# Mathdi

Modern EdTech application built with React, Tailwind and Supabase.

## Overview
This project is a UI + architecture-ready prototype for an educational quiz platform.  
It includes full frontend structure and scalable foundation for backend integration.

## Features
- Modern responsive UI
- Authentication layout (Supabase ready)
- Quiz interface (UI prototype)
- Results page design
- Component-based architecture

## Tech Stack
- React + Vite
- Tailwind CSS
- Supabase (prepared integration)

## Status
This is a UI/Frontend prototype.  
Core quiz logic and scoring system can be extended or customized depending on use case.

## Setup
npm install  
npm run dev
